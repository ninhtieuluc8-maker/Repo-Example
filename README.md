# FocusFlow — repo mẫu

Một ứng dụng quản lý việc cần làm nhỏ, viết bằng HTML, CSS và JavaScript thuần. Dự án có thể mở trực tiếp mà không cần cài đặt phụ thuộc.

## Chạy dự án

Mở `index.html` bằng trình duyệt, hoặc chạy một máy chủ tĩnh từ thư mục gốc:

```bash
python3 -m http.server 8080
```

Sau đó truy cập [http://localhost:8080](http://localhost:8080).

## Tính năng

- Thêm công việc với mức độ ưu tiên.
- Đánh dấu hoàn thành, xoá và lọc công việc.
- Theo dõi tiến độ trong ngày.
- Tự động lưu danh sách vào `localStorage` của trình duyệt.
